### 1.安装下载

需要到chatgpt官网下载。

### 2.本地文件读写

###### 2.1 新建项目。

可以新建项目或者选择本地文件夹。

###### 2.2 权限设置

有三种权限：默认权限、自动审查和完全访问权限。一般都选择自动审查。

###### 2.3 限制

无法像是在Vscode当中，在一个文件夹下面打开它的子文件夹。如果要打开新的文件夹，只能是作为一个新的项目来打开。

### 3.命令行使用

在打开自动审查模式后，我们可以直接用自然语言的方式，让Codex用命令行开展操作。 包括安装依赖、下载软件、下载skill等等。

### 4.持久化记忆

###### 4.1 全局长期记忆

全局生效的`Agents.md` 不管在哪个项目和Codex进行对话，都会把我们已经记录好的全局记忆当作上下文传给大模型。适合记录所有任务都通用的规则，比如你的使用习惯、工作偏好等。

直接在`自定义指令` 当中添加想要的规则和约束。

也可以在聊天当中使用自然语言，告诉Codex把你想添加的添加到`全局agents.md`

###### 5.2 插件大全

| 插件          | 功能                                   |
| ----------- | ------------------------------------ |
| Chrome      | 用你的浏览器处理网页任务，可以查资料，测试页面，整理网页信息等。     |
| GitHub      | 查看仓库、PR、Issue 和 CI 状态，适合代码协作、审查和发布流程 |
| Vercel      | 构建和部署 Web 应用、Agent、预览环境。             |
| Sentry      | 查看线上错误和事件，帮助定位 bug、复现问题和评估影响范围。      |
| Superpowers | 强大agent工具包，辅助规划、TDD、调试和交付工程任务。       |

注：有的并没有在插件的首页，可以直接搜索名字获取。
