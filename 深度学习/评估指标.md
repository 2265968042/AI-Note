# 评估指标

## 1.BLEU

BLEU是一种在机器翻译领域广泛采用的评估指标，其通过计算机器翻译输出（候选文本）与参考翻译文本（参考文本）之间的词汇相似度来评估翻译质量。BLEU主要计算候选文本与参考文本的$n$元组共现频率，评分结果在[0,1]的区间内，具体的计算方式如下所示：

$$
BLEU=BP\times exp(\sum_{n=1}^N w_n \times \log p_n)
$$

其中，$w_n$是$n$元组的权重，用于调整不同长度的$n$ 元组对最终评分的影响。具体实践中，研究者通常设$n=4$，并平均分配$w_n$ 。$BP$表示长度惩罚因子，用于修正由于候选文本长度过短导致的评分偏差，其计算方式为：

$$
\mathrm{BP} =
\begin{cases}
1, & \text{if } l_c > l_r, \\
\exp\!\left(1 - \dfrac{l_r}{l_c}\right), & \text{if } l_c \le l_r .
\end{cases}

$$

这里，$𝑙_𝑐$ 和$l_r$分别表示候选文本的长度和最短的参考文本长度。

BP 用来惩罚“候选翻译过短”的情况；  如果生成的句子不短于参考答案，就不惩罚；  如果明显更短，就指数级惩罚。BP 的“狠”不在指数本身，而在指数里那个“长度在分母”的设计。

**公式当中的$p_n$代表$n$元组的精确率****，计算公式如下：

$$
p_{n}=\frac{\sum_{\mathrm{n}-\text { gram } \in C} \min \left(\operatorname{count}_{C}(\mathrm{n}-\mathrm{gram}), \max _{R \in \mathcal{R}} \operatorname{count}_{R}(\mathrm{n}-\mathrm{gram})\right)}{\sum_{\mathrm{n} \text {-gram } \in C} \operatorname{count}_{C}(\mathrm{n} \text {-gram })}
$$

- C：candidate（候选译文）

- $R$：参考译文集合（可能有多个参考 $R$）

- $n-gram∈C$：候选中出现的所有$ n-gram $类型（更严格说是对候选中所有 $n-gram$ 计数求和）

- $countC​(n-gram)：该 n-gram 在候选 C 中出现了多少次$

- $countR​(n-gram)：该 n-gram 在某个参考 R 中出现的次数$

- $maxR∈R​countR​(n-gram)$：在所有参考里，这个 $n-gram $出现次数的最大值

- $min(⋅,⋅)$：**裁剪（clipping）**：候选的计数不能超过参考允许的上限

**n-gram 就是“由连续的 n 个词（或子词、字符）组成的片段”。**

- **连续**（不能跳词）

- **长度为 n**

- 是语言中的“局部模式”

假设一句话是：

> **“the cat is on the mat”**

**1-gram（unigram）**

每一个单独的词：

`the | cat | is | on | the | mat`

**2-gram（bigram）**

相邻两个词组成的片段：

`the cat | cat is | is on | on the | the mat`

在做$ n-gram$ 划分时，随着$ n$ 的增大得分越来越低。这个是很直观的，当$ n$ 非常大时就等于是要求生成的结果必须和人工标注的译文一摸一样才能得分

你这句话里，有多少“连续词片段”能在参考答案里找到，同时不允许你靠重复或过短来作弊。

## 2.ROUGE指标

ROUGE指标总共有四种：Rouge-N、Rouge-L、Rouge-W、Rouge-S。相比于BLEU计算的是准确率，ROUGE指标计算的是召回率，即强调文本信息的覆盖度和完整度。

### 2.1 Rouge-N指标

Rouge-N的就是将模型生成的结果和标注结果按照n-gram划分后，计算召回率。

公式为：

$$
ROUGE-n=\frac{\sum_{\mathrm{n} \text {-gram } \in R} \min \left(\operatorname{count}_{C}(\mathrm{n} \text {-gram }), \operatorname{count}_{R}(\mathrm{n} \text {-gram })\right)}{\sum_{\mathrm{n} \text {-gram } \in R} \operatorname{count}_{R}(\mathrm{n} \text {-gram })}
$$

- C：candidate（候选译文）

- R：参考译文集合（可能有多个参考 R）

- n-gram∈C：候选中出现的所有 n-gram 类型（更严格说是对候选中所有 n-gram 计数求和）

- countC​(n-gram)：该 n-gram 在候选 C 中出现了多少次

- countR​(n-gram)：该 n-gram 在某个参考 R 中出现的次数

- maxR∈R​countR​(n-gram)：在所有参考里，这个 n-gram 出现次数的最大值

- min(⋅,⋅)：**裁剪（clipping）**：候选的计数不能超过参考允许的上限

这个Rouge-N和上面BLEU当中的$p_n$有什么区别呢？

BLEU里面的分母是$countC​(n-gram)：该 n-gram 在候选 C 中出现了多少次$

而Rouge-N里面的分母是：$countR​(n-gram)：该 n-gram 在某个参考 R 中出现的次数$

它们的含义也是不同的，BLEU当中的$p_n$关心的是“我说的这些，有多少是真的对的。

ROUGE-n关心的是“我说的这些，有多少是真的对的。

### 2.2.Rougle-L指标

无论是BLEU指标还是Rougle-N指标都是使用的词袋模型，它们都不考虑词语之间的相对顺序。这句话其实是有问题的，BLEU和Rougle-N其实是考虑了局部顺序的，只是没有考虑长距离顺序和全局顺序而已。

而Rougle-L指标考虑了词语之间的相对顺序。这里的L表示的是Longest Common Subsequence（最长公共子序列：注意这个是非连续的。）

Rougle-L以F1分数计算，结合了精确率和召回率的信息。精确率衡量了候选文本中有多少内容是与参考文本相关的，而召回率则衡量了参考文本中有多少内容被候选文本所覆盖。具体的计算公式如下:

$$
\begin{aligned} 
\text { Recall } & =\frac{\operatorname{LCS}(C, R)}{\operatorname{length}(R)} \\ 
\text { Precision } & =\frac{\operatorname{LCS}(C, R)}{\text { length }(C)} \\ 
\mathrm{F_\beta}  & =\frac{\left(1+\beta^{2}\right) \cdot \text { Precision } \cdot \text { Recall }}{\left(\beta^{2} \cdot \text { Precision }\right)+\text { Recall }}
\end{aligned}
$$

在上述公式中，$LCS(C,R)$表示$C$和$R$之间的最长公共子序列长度。$length(c)$和$length(R)$分别代表候选文本和参考文本的长度。在ROUGLE-L中，$\beta$用于决定召回率的权重。

它用 **最长公共子序列 LCS** 来衡量候选文本 C 和参考文本 R 的“顺序一致性”和“内容覆盖”。

$LCS(C,R)$表示$C$和$R$之间的最长公共子序列长度。

- 子序列”允许**跳过一些词**，但要求**相对顺序不变**

- 不是“连续片段”（那叫 substring），LCS 更宽松

$Recall$ 高意味着：**参考的大部分信息，你都提到了（并且顺序大体对）。**

$Precision$你写的内容有多少是真的“对得上参考”的？

其实这里$F_\beta$是$Recall$和$Precision$ 的调和平均。

调和平均是“倒数的算术平均的倒数”。调和平均相较于算术平均与几何平均，对较小值更加敏感，因此能够有效惩罚 Precision 与 Recall 中的短板，这正符合信息检索与生成任务的评价需求。

下面介绍几种平均

- 算术平均：$A(a,b)=\frac {a+b}{2}$

- 几何平均：$G(a,b)=\sqrt{ab}$

- 调和平均：$H(a,b)=\frac{2}{\frac 1 a+\frac 1 b}=\frac{2ab}{a+b}$

### 2.3 Rouge-W指标

Rouge-L指标虽然考虑了词语之间的相对顺序，但是由于其使用最长公共子序列，所以没有考虑到词语之间是否连续的问题。

**例如，参考文本为 R=“A B C D E”，候选文本 C1=“A B C”与 C2=“A C E”在 ROUGE-L 下都可能得到相同的 LCS 长度（均为 3），从而分数相同**，但显然 C1 的连续匹配更符合人类直觉。如果使用Rougle-L计算的话，得分是相同的。所以提出了Rougle-W指标。Rouge-W就是给连续匹配到的子序列更高的权重，最终让连续匹配的结果要比非连续匹配的结果得分更高一些。

Rouge-W的计算公式如下：

$$
\begin{aligned}
\text{Recall}_{W} &= \frac{\operatorname{WLCS}(C, R)}{\operatorname{length}(R)}, \\
\text{Precision}_{W} &= \frac{\operatorname{WLCS}(C, R)}{\operatorname{length}(C)}, \\
\mathrm{ROUGE\text{-}W}
&=
\frac{(1+\beta^2)\cdot \text{Precision}_{W}\cdot \text{Recall}_{W}}
{\beta^2\cdot \text{Precision}_{W} + \text{Recall}_{W}}, \\
\operatorname{WLCS}(C,R)
&=
\sum_{i=1}^{k} \ell_i^2 .
\end{aligned}

$$

对上面的公式进行分析：

其中$
\operatorname{WLCS}(C,R)$ 当中的

$l_i$是第$i$个连续偏度的长度

$k$ 是连续匹配片段的个数

$f(·)$是加权函数（对连续性进行奖励）。这里面用的是平方和。

举个例子来进行说明：

参考句子$R= A B C D E$

候选句子$C1=A B C$

候选句子$C2=A C E$

首先计算$LCS$：

$LCS(C1,R)=3$

$LCS(C2,R)=3$

然后计算$WLCS:$

$WLCS(C1,R)=3^2=9$

$WLCS(C2,R)=1^2+1^2+1^2=3$

## 2.4 Rouge-S指标

在Rouge-N中对文本做2-gram划分时，都是连续的进行划分。在Rouge-S中使用的skip-bigram则是在划分时允许跳过一些词。

$$
\begin{aligned}
R_{\text{skip2}} &= \frac{\operatorname{SKIP2}(X, Y)}{\binom{m}{2}}, \\
P_{\text{skip2}} &= \frac{\operatorname{SKIP2}(X, Y)}{\binom{n}{2}}, \\
F_{\text{skip2}} &=
\frac{(1+\beta^2)\,R_{\text{skip2}}\,P_{\text{skip2}}}
{R_{\text{skip2}} + \beta^2 P_{\text{skip2}}}.
\end{aligned}

$$

$SKIP2(X,Y)$是什么呢？候选 $X$ 里出现的 $skip-2 bigram$，和参考$Y$ 里出现的 $skip-2 bigram$，有多少是重合的（匹配的）。

$\binom{m}{2}=\frac{m(m-1)}{2}$

$SKIP2(X,Y)$ 是“候选与参考匹配到的$ skip-2$ 二元组数量”，  
$\binom{m}{2}$是“参考长度为 $m$ 时最多能产生的二元组数量上界”，



上面这些都是传统的一些NLP方法，现在主流是语义相似度（embedding / cosine）＋ 传统指标并行使用。

# 3. 分类指标

## 3.1 A、P、R、F1

|             | 预测值P(Positives)    | 预测值N(Negatives)    |
| ----------- | ------------------ | ------------------ |
| 真实值T(Ture)  | TP：正样本，预测结果为正（真阳性） | FN:正样本，预测结果为负（假阴性） |
| 真实值F(False) | FP：负样本，预测结果为正（假阳性） | TN：负样本，预测结果为负（真阴性） |

正样本与负样本的区别，在于它们是否满足当前任务所定义的“目标条件”。

正负样本是训练目标下的人为标注结果。

准确率：所有预测正确的正例和负例，占所有样本的比例，其定义为：

$Accuracy =\frac{T P+T N}{P+N}$

精确率：模型预测为正例的样本中真正为正例的比例，其定义为：$Precision=\frac{TP}{TP+FP}$

召回率：所有真正为正例的样本中被模型正确预测出来的比例，其定义为：$Reacll=\frac{TP}{TP+FN}$

$F1$分数：是精确率和召回率的调和平均数，用于衡量模型再分类任务上的综合性能，其定义为：$F1 =2 \times \frac{\text { Precision } \times \text { Recall }}{\text { Precision }+ \text { Recall }}$



## 3.2 P-R曲线

P-R曲线：通过选择不同的阈值，得到$Recall$和$Precision$，以$Recall$为横坐标，$Precision$为纵坐标得到的曲线图。

$P–R$ 曲线里的“阈值”，是把模型的“连续输出分数”转换成“正/负预测”的分界点。大多数模型输出的不是“0/1”，而是一个“置信度 / 得分”。阈值 = 决定“多大分数才算正样本。



$PR$ 曲线性质：

- 如果一个学习器的$PR$ 曲线被另一个学习器的曲线完全包住，说明后者性能优于前者。

- 如果两个学习器的曲线相交，可以通过平衡点来度量性能。在 $P–R $语境中，**平衡点** 通常指**Precision = Recall 的那个点**

当阈值下降时：

- $Recall$ 不断增加，因为越来越多的样本被划分为正例。当阈值为0时，所有样本都被划分为正样本了，此时$Recall$ 为1

- $Precision$ 正例被判为正例变多了，但是负例被判为正例也变多了。所以$Precision$ 会震荡下降，而不是严格递减。

- $AP$ : $Precision-Recall$ 曲线下围成的面积，一般一个分类器性能越好，$AP$值越高。如果一个分类器可以把正负样本完全区分开来，那么曲线下的面积是1。

- $mAP$ ：多个类别$AP$ 的平均值。



## 3.3 ROC-AUC

**ROC**曲线：**曲线的横坐标为假正例率（FPR），即实际为负的样本有多少被预测为正；纵坐标为TPR(真正例率)，即实际为正的样本多少被预测为正**。

**AUC (Area under Curve)**：即ROC曲线下的面积，介于0.5和1之间，作为数值可以直观的评价分类器的好坏，值越大越好。

**ROC–AUC 衡量的是：  模型把“正样本排在负样本前面”的能力。** 它不是在评价某一个阈值下的准确率，而是：**在所有可能阈值下，模型整体区分正负样本的能力。**

**好模型**：

- 在很小的 FPR 下，就能获得很高的 TPR

- 曲线**向左上角凸起**
